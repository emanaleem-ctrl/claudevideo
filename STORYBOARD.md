# Infinite subagents — storyboard

Logline: Clawd wants a coffee, but instead of making it, it spawns subagents, which spawn subagents, until hundreds of them build a machine that produces one tiny cup, which needs sugar, so they all start over.

Format: 1920×1080 (16:9), 24 fps, 15.0 s, built to loop (the last wipe covers the frame, the first one uncovers it).

World: one desk, one continuous camera. Warm cream wall (#F1E6D0), muted teal desktop (#6F9C98) so terracotta Clawds pop, coffee browns (#6B4128), a yellow sticky note (#F6D66B). No watercolour fills (no GPU): flat washes + ink. Colour arc: calm and empty → dense and busy → still → the same calm desk.

Motif: the coffee cup. It's the icon on the note, the tiny cup at the end of the machine, and the thing handed back. The sugar cube is the sleeper's pillow in the swarm (easter egg) and the payoff icon.

Clawd's arc: neutral → surprised (note) → determined (knuckles) → thinking → idea → happy → surprised (pop pop) → starstruck (swarm) → proud (supervisor) → hopeful (cup arrives) → sip → deadpan → deadpan with the sugar thought.

Sound (synthesized in code): note pop, knuckle cracks, idea ding, spawn pops that snowball into a swarm bustle (footstep ticks, machine clunks on the beat, ratchet), a DING when the cup fills and then hard silence, tiny footsteps, a slurp, a silent beat, a thought-bubble pop, a freeze hit, the bustle bursting back, a brush swoosh.

Note: the approved beat sheet had 5–10 swarm, 10–13 walk, 13–15 sip + hand back + freeze + restart. The last beat has four reads, so it gets more time: swarm 4.4–9.4, walk 9.4–12.2, sip/hand back/freeze/restart 12.2–15.0.
